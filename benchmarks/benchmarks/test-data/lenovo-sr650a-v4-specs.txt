Lenovo ThinkSystem SR650a V4 Server - Technical Specifications

Product Overview
The Lenovo ThinkSystem SR650a V4 is a 2U rack server designed for demanding AI, machine learning, and high-performance computing workloads. It features support for the latest AMD EPYC processors and NVIDIA GPUs, delivering exceptional compute density and energy efficiency for the modern data center.

Processor Support
The SR650a V4 supports up to two AMD EPYC 9004 Series processors (Genoa and Bergamo). The maximum core count per socket is 128 cores with Bergamo processors, enabling up to 256 total cores per server. The processors operate at a base TDP of 360W per socket. The server supports DDR5-4800 memory with up to 24 DIMM slots, for a maximum memory capacity of 4.6 TB using 192 GB RDIMMs.

GPU Acceleration
The server supports up to four double-width PCIe Gen5 x16 GPU accelerators. Supported GPU models include the NVIDIA RTX PRO 6000 Blackwell Server Edition (96 GB GDDR7), NVIDIA H100 NVL (94 GB HBM3), and NVIDIA L40S (48 GB GDDR6). For AI inference workloads, the NVIDIA RTX PRO 6000 Blackwell provides 4,000 TOPS of INT8 performance and supports Multi-Instance GPU (MIG) technology, which allows a single GPU to be partitioned into up to seven isolated instances. The total GPU memory in a fully populated configuration with 4x RTX PRO 6000 is 384 GB.

Storage Configuration
The SR650a V4 offers flexible storage options including up to 16x 2.5-inch SAS/SATA/NVMe drive bays in the front, plus up to 4x 2.5-inch NVMe rear bays, for a total of 20 drive bays. Maximum raw storage capacity is 368 TB using 16 TB NVMe drives. The server includes a dedicated M.2 boot drive slot supporting two mirrored M.2 NVMe SSDs for operating system redundancy.

Network Connectivity
Standard networking includes one OCP 3.0 slot supporting 10 GbE, 25 GbE, or 100 GbE network adapters. The server also has two additional PCIe Gen5 expansion slots for optional network interface cards. For high-performance computing clusters, the server supports NVIDIA ConnectX-7 InfiniBand adapters delivering up to 400 Gb/s bandwidth per port.

Power and Cooling
The SR650a V4 uses high-efficiency titanium-rated power supplies available in 1100W, 1800W, and 2400W configurations. Redundant hot-swap power supplies (1+1) ensure continuous operation during power supply maintenance. The cooling system features variable-speed fans with N+1 redundancy and supports ambient operating temperatures from 5°C to 40°C (ASHRAE A3 compliant). Direct liquid cooling (DLC) is available as an option for maximum cooling efficiency in high-density deployments. The idle power consumption is approximately 350W, while typical GPU workload power consumption ranges from 1800W to 2200W.

Management Features
Lenovo XClarity Controller (XCC2) provides advanced out-of-band management capabilities including remote console access, firmware updates, and hardware monitoring. The XCC2 supports Redfish API, IPMI 2.0, and SNMP v3 for integration with existing data center management tools. Lenovo XClarity Administrator (LXCA) enables fleet management of up to 10,000 servers with automated firmware compliance, configuration patterns, and operating system deployment.

Physical Dimensions
The SR650a V4 is a 2U form factor measuring 868mm (34.2 inches) in depth, 482mm (18.9 inches) in width, and 87mm (3.4 inches) in height. The maximum weight with full configuration is 35 kg (77.2 lbs). The server is compatible with standard 19-inch rack mounting and ships with tool-less rail kits.

Warranty and Support
The standard warranty is a 3-year limited warranty with on-site service. Extended warranty options are available for up to 5 years with 24x7x4-hour response time. Lenovo Premier Support provides a dedicated technical account manager and prioritized case handling.

Operating System Support
The SR650a V4 is certified for Red Hat Enterprise Linux 8.x and 9.x, SUSE Linux Enterprise Server 15 SP4 and later, Ubuntu Server 22.04 LTS and 24.04 LTS, VMware vSphere 8.0 and later, and Microsoft Windows Server 2022. For AI and ML workloads, Ubuntu 24.04 LTS is the recommended operating system due to its comprehensive NVIDIA driver and CUDA toolkit support.

Pricing
The base configuration of the SR650a V4 with one AMD EPYC 9354P processor, 256 GB DDR5 memory, and no GPU starts at $12,500 USD. A fully configured system with two EPYC 9754 processors, 2 TB DDR5 memory, 4x NVIDIA RTX PRO 6000 GPUs, and 100 TB NVMe storage has a list price of approximately $185,000 USD. Volume pricing discounts of 15-25% are available for orders of 10 or more units.
